### BuffOut

Fades out buff bars when out of combat.

**Options:**

**General Settings**
- Out of Combat Timeout (seconds)

**Fading Settings**
- Fade-In Duration (seconds)
- Fade-Out Duration (seconds)
- Out of Combat Opacity
